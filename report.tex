\section{مقدمه}\label{sec:introduction}

\subsection{تعریف مسئله تحقیق}\label{subsec:problem_definition}

\vspace{0.5cm}

{\yekanfont \textbf{مسئله اصلی}}: سیستم‌های بهداشتی امروز با چالش یکپارچه‌سازی\footnote{Data Integration} داده‌های متنوع و ارائه پشتیبانی تصمیم‌گیری مناسب برای نقش‌های مختلف مواجه هستند. سیستم‌های پشتیبانی تصمیم‌گیری\footnote{Decision Support System (DSS)} موجود اغلب:

\begin{itemize}[topsep=0.5em]
\item قادر به پردازش همزمان\footnote{Concurrent Processing} انواع مختلف داده‌های بهداشتی نیستند
\item رابط کاربری\footnote{User Interface} یکسان برای نقش‌های مختلف ارائه می‌دهند
\item از الگوریتم‌های یادگیری ماشین\footnote{Machine Learning Algorithms} مدرن استفاده نمی‌کنند
\end{itemize}

\vspace{0.5cm}

{\iranfont \textbf{سؤال تحقیق}}: آیا می‌توان با ترکیب چارچوب نظری\footnote{Theoretical Framework} سیستم‌های پشتیبانی تصمیم‌گیری، الگوریتم‌های یادگیری ماشین مدرن، و طراحی مبتنی بر نقش\footnote{Role-based Design}، سیستمی طراحی کرد که بتواند مسائل مختلف بهداشتی را به‌طور مؤثر حل کند؟

\vspace{0.5cm}

\textbf{فرضیه تحقیق}: پیاده‌سازی سیستم پشتیبانی تصمیم‌گیری مبتنی بر چارچوب توربان-شاردا-دلن\footnote{Turban-Sharda-Delen Framework} با استفاده از الگوریتم‌های یادگیری ماشین و طراحی مبتنی بر نقش، می‌تواند عملکرد تصمیم‌گیری در حوزه‌های مختلف بهداشتی را بهبود دهد.

\vspace{0.5cm}

کتاب «تحلیل‌ها، علم داده و هوش مصنوعی: سیستم‌های پشتیبانی تصمیم‌گیری»\footnote{Analytics, Data Science, \& Artificial Intelligence: Systems for Decision Support (11th Edition)} نوشته توربان، شاردا و دلن چارچوب جامعی برای طراحی و پیاده‌سازی سیستم‌های پشتیبانی تصمیم‌گیری ارائه می‌دهد. 

این چارچوب بر اساس مدل چهار مرحله‌ای هربرت سایمون\footnote{Herbert Simon's Four-Phase Decision Model} شامل مراحل هوشمندی\footnote{Intelligence Phase}، طراحی\footnote{Design Phase}، انتخاب\footnote{Choice Phase} و پیاده‌سازی\footnote{Implementation Phase} است.

در این پروژه، یک سیستم پشتیبانی تصمیم‌گیری جامع برای مراقبت‌های بهداشتی\footnote{Healthcare} پیاده‌سازی شده است که از چهار زیرسیستم اصلی تشکیل شده: مدیریت داده‌ها\footnote{Data Management Subsystem}، مدیریت مدل‌ها\footnote{Model Management Subsystem}، مدیریت دانش\footnote{Knowledge Management Subsystem} و رابط کاربری. 

سیستم با استفاده از الگوریتم‌های یادگیری ماشین مختلف شامل جنگل تصادفی\footnote{Random Forest}، تقویت گرادیان شدید\footnote{XGBoost (Extreme Gradient Boosting)}، تقویت گرادیان سبک\footnote{LightGBM (Light Gradient Boosting Machine)} و ماشین بردار پشتیبان\footnote{Support Vector Machine (SVM)}، قابلیت تحلیل و پیش‌بینی در حوزه‌های مختلف بهداشتی را فراهم می‌آورد.

\subsection{مسائل حل شده توسط سیستم}\label{subsec:solved_problems}

سیستم طراحی شده برای حل چهار دسته مسئله اصلی در مراقبت‌های بهداشتی طراحی شده است:

\textbf{۱. مسائل تشخیص و پیش‌بینی بالینی}: شامل تشخیص زودهنگام\footnote{Early Detection} سرطان پستان\footnote{Breast Cancer}، پیش‌بینی پیشرفت دیابت\footnote{Diabetes Progression Prediction}، و ارزیابی ریسک\footnote{Risk Assessment} بستری مجدد بیماران که از طریق داشبورد کادر بالینی\footnote{Clinical Staff Dashboard} قابل دسترسی است.

\textbf{۲. مسائل مدیریت منابع و ظرفیت}: شامل بهینه‌سازی ظرفیت\footnote{Capacity Optimization} بیمارستان، تخصیص بهینه\footnote{Optimal Allocation} تخت‌ها، و مدیریت جریان بیماران\footnote{Patient Flow Management} که از طریق داشبورد مدیریت اجرایی\footnote{Administrative Executive Dashboard} پشتیبانی می‌شود.

\textbf{۳. مسائل ارزیابی عملکرد}: شامل نظارت بر عملکرد کادر\footnote{Staff Performance Monitoring}، ارزیابی کیفیت بخش‌ها\footnote{Department Quality Assessment}، و تحلیل رضایت بیماران\footnote{Patient Satisfaction Analysis} که از طریق داشبورد مدیر بخش\footnote{Department Manager Dashboard} قابل پیگیری است.

\textbf{۴. مسائل مالی و استراتژیک}: شامل تحلیل هزینه‌های بهداشتی\footnote{Healthcare Cost Analysis}، پیش‌بینی درآمد\footnote{Revenue Prediction}، و بهینه‌سازی بودجه\footnote{Budget Optimization} که از طریق داشبورد مدیر مالی\footnote{Financial Manager Dashboard} و رهبری بحرانی\footnote{Critical Leadership Dashboard} پشتیبانی می‌شود.

\section{روش کار}\label{sec:methodology}

این پروژه با هدف حل مسائل عملی در سیستم‌های بهداشتی، از روش‌شناسی ترکیبی استفاده کرده که شامل سه رویکرد اصلی است:

\subsection{روش‌شناسی کلی پروژه}\label{subsec:general_methodology}

{\yekanfont \textbf{رویکرد اول - چارچوب نظری}}: پیاده‌سازی بر اساس چارچوب نظری کتاب توربان، شاردا و دلن و مدل چهار مرحله‌ای هربرت سایمون برای تصمیم‌گیری انجام شده است.

{\iranfont \textbf{رویکرد دوم - روش‌شناسی کریسپ-دی‌ام}}: برای توسعه مدل‌های یادگیری ماشین از روش‌شناسی شش مرحله‌ای کریسپ-دی‌ام\footnote{Cross-Industry Standard Process for Data Mining (CRISP-DM)} استفاده شده که شامل درک کسب‌وکار، درک داده‌ها، آماده‌سازی داده‌ها، مدل‌سازی، ارزیابی و استقرار است.

\textbf{رویکرد سوم - آزمایش تجربی}: برای اعتبارسنجی فرضیه‌های تحقیق، طرح آزمایشی جامع طراحی شده که شامل:
\begin{itemize}
\item آزمایش عملکرد \lr{8} الگوریتم یادگیری ماشین بر روی \lr{12} مجموعه‌داده مختلف
\item مقایسه تطبیقی الگوریتم‌ها با معیارهای استاندارد (دقت\footnote{Accuracy}، دقت مثبت\footnote{Precision}، حساسیت\footnote{Recall/Sensitivity}، امتیاز F1\footnote{F1-Score})
\item ارزیابی کیفیت سیستم از طریق ۱۵۹ تست واحد و یکپارچگی
\item تحلیل آماری نتایج برای تعیین بهترین الگوریتم برای هر نوع مسئله
\end{itemize}

\subsection{داده‌ها و آماده‌سازی}\label{subsec:data_preparation}

\subsubsection{مجموعه‌داده‌های مورد استفاده}\label{subsubsec:datasets}

سیستم از ۱۲ مجموعه‌داده مختلف استفاده می‌کند که شامل داده‌های واقعی\footnote{Real-world Data} و مصنوعی\footnote{Synthetic Data} است:

{\yekanfont \textbf{مجموعه‌داده‌های واقعی}}:
\begin{itemize}
\item \textbf{دیابت}\footnote{Diabetes Dataset} (\lr{442} نمونه، \lr{10} ویژگی): پیش‌بینی پیشرفت بیماری دیابت با متغیر هدف رگرسیون\footnote{Regression Task Type}
  - ویژگی‌های کلیدی: سن\footnote{Age}، جنس\footnote{Gender}، شاخص توده بدنی\footnote{Body Mass Index (BMI)}، فشار خون\footnote{Blood Pressure}، شش متغیر سرمی\footnote{Serum Variables} نرمال‌سازی شده
  - متغیر هدف اصلی: مقدار پیوسته ۲۱۴ مقدار منحصربه‌فرد، دامنه ۲۵-۳۴۶
  - عملکرد بهترین مدل: رگرسیون خطی با ضریب تعیین ۰.۴۵۳

\item \textbf{سرطان پستان}\footnote{Breast Cancer Dataset} (\lr{569} نمونه، \lr{30} ویژگی): تشخیص سرطان پستان با دقت بالا
  - ویژگی‌های کلیدی: شعاع میانگین\footnote{Mean Radius}، بافت میانگین\footnote{Mean Texture}، محیط میانگین\footnote{Mean Perimeter}، مساحت میانگین\footnote{Mean Area}، نرمی میانگین\footnote{Mean Smoothness}
  - متغیر هدف اصلی: طبقه‌بندی دوکلاسه\footnote{Binary Classification}: ۰=بدخیم، ۱=خوش‌خیم
  - عملکرد بهترین مدل: رگرسیون لجستیک با دقت ۹۸.۲٪
\item \textbf{شراب}\footnote{Wine Dataset} (\lr{178} نمونه، \lr{13} ویژگی): طبقه‌بندی انواع شراب برای تحقیقات پزشکی
  - ویژگی‌های کلیدی: الکل\footnote{Alcohol Content}، اسید مالیک\footnote{Malic Acid}، فلاونوئیدها\footnote{Flavonoids}، فنول‌های غیرفلاونوئیدی\footnote{Non-flavonoid Phenols}
  - متغیر هدف: طبقه‌بندی سه‌کلاسه\footnote{Three-class Classification}
  - عملکرد بهترین مدل: جنگل تصادفی با دقت ۱۰۰٪

\item \textbf{ظرفیت بیمارستان}\footnote{Hospital Capacity Dataset} (\lr{20,640} نمونه، \lr{8} ویژگی): داده‌های ظرفیت بیمارستان
  - ویژگی‌های کلیدی: تعداد تخت\footnote{Number of Beds}، سن بیمار\footnote{Patient Age}، نسبت کادر\footnote{Staff Ratio}، فاصله تا مرکز\footnote{Distance to Center}
  - متغیر هدف اصلی: مقدار ظرفیت (۳,۸۴۲ مقدار منحصربه‌فرد، دامنه ۰.۱۵-۵.۰)
  - عملکرد بهترین مدل: جنگل تصادفی با ضریب تعیین ۰.۸۰۵

\item \textbf{هزینه‌های بهداشتی جهانی}\footnote{Global Healthcare Expenditure Dataset} (\lr{117} نمونه، \lr{14} ویژگی): هزینه‌های بهداشتی \lr{16} کشور از \lr{2015} تا \lr{2024}
  - کامل بودن داده‌ها: \lr{94.2\%} (\lr{68} مقدار گمشده از \lr{1,170} مقدار کل)
  - بالاترین هزینه سرانه: \lr{2,422.64} دلار سالانه
  - کمترین هزینه سرانه: \lr{33.99} دلار سالانه
\end{itemize}

{\iranfont \textbf{مجموعه‌داده‌های مصنوعی}}:
\begin{itemize}
\item \textbf{جمعیت‌شناسی بیماران}\footnote{Patient Demographics Synthetic Dataset} (\lr{1,000} نمونه، \lr{20} ویژگی): ویژگی‌های جمعیت‌شناختی بیماران
  - متغیر هدف اصلی: ریسک بستری مجدد (۱,۰۰۰ مقدار منحصربه‌فرد، دامنه ۰-۱)
  - شامل: سن، جنس، وزن\footnote{Weight}، قد\footnote{Height}، شاخص توده بدنی، فشار خون، ضربان قلب\footnote{Heart Rate}، کلسترول\footnote{Cholesterol}، گلوکز\footnote{Glucose}

\item \textbf{نتایج بالینی}\footnote{Clinical Outcomes Synthetic Dataset} (\lr{1,000} نمونه، \lr{7} ویژگی): نتایج درمان و رضایت بیماران
  - متغیرهای هدف: موفقیت درمان (طبقه‌بندی دوکلاسه)، امتیاز کیفیت زندگی (۱,۰۰۰ مقدار منحصربه‌فرد)
  - عملکرد بهترین مدل: رگرسیون خطی با ضریب تعیین ۰.۰۰۲ برای امتیاز کیفیت زندگی

\item \textbf{عملکرد کادر}\footnote{Staff Performance Synthetic Dataset} (\lr{200} نمونه، \lr{9} ویژگی): ارزیابی عملکرد کارکنان
  - متغیرهای هدف: امتیاز رضایت بیمار، رتبه‌بندی عملکرد (هر کدام ۲۰۰ مقدار منحصربه‌فرد)
  - ویژگی‌های کلیدی: زمان پاسخ به دقیقه\footnote{Response Time in Minutes}، ساعات اضافه‌کاری\footnote{Overtime Hours}، سال‌های تجربه\footnote{Years of Experience}، بخش

\item \textbf{عملکرد بخش‌ها}\footnote{Department Performance Synthetic Dataset} (\lr{7} نمونه، \lr{8} ویژگی): کارایی ۷ بخش مختلف بیمارستان
  - متغیر هدف اصلی: امتیاز کیفیت (۷ مقدار منحصربه‌فرد)
  - بخش‌ها: اورژانس\footnote{Emergency}، قلب\footnote{Cardiology}، انکولوژی\footnote{Oncology}، اطفال\footnote{Pediatrics}، جراحی\footnote{Surgery}، مراقبت‌های ویژه\footnote{Intensive Care}، رادیولوژی\footnote{Radiology}

\item \textbf{معیارهای مالی}\footnote{Financial Metrics Synthetic Dataset} (\lr{24} نمونه، \lr{8} ویژگی): شاخص‌های مالی ۲۴ ماه
  - متغیرهای کلیدی: درآمد\footnote{Revenue}، هزینه‌ها\footnote{Costs}، حجم بیماران\footnote{Patient Volume}، میانگین مدت اقامت\footnote{Average Length of Stay}
  - عملکرد بهترین مدل: رگرسیون خطی با ضریب تعیین ۰.۳۷۹

\item \textbf{اثربخشی دارو}\footnote{Medication Effectiveness Dataset} (\lr{178} نمونه، \lr{14} ویژگی): تحلیل اثربخشی داروها
  - متغیر هدف اصلی: اثربخشی (۳ مقدار منحصربه‌فرد)
  - شامل ۱۳ جزء و نوع دارو\footnote{Drug Components and Type}
\end{itemize}

\textbf{چالش‌های عملکرد مدل}:
\begin{itemize}
\item \textbf{عملکرد متغیر}\footnote{Variable Performance}: تفاوت قابل‌توجه در عملکرد مدل‌ها (از \lr{$R^2 = -0.055$} تا \lr{0.805}) بسته به نوع و کیفیت داده‌ها
\item \textbf{بهینه‌سازی هایپرپارامتر}\footnote{Hyperparameter Optimization}: تنظیم دقیق پارامترهای \lr{8} الگوریتم مختلف برای دستیابی به بهترین عملکرد
\item \textbf{اعتبارسنجی متقابل}\footnote{Cross-validation Complexity}: اطمینان از قابلیت تعمیم مدل‌ها در محیط‌های مختلف بالینی
\item \textbf{تفسیرپذیری مدل}\footnote{Model Interpretability}: ارائه توضیحات قابل‌فهم برای تصمیمات مدل‌های پیچیده به کادر پزشکی
\end{itemize}

\subsubsection{چالش‌های یکپارچگی و سازگاری}\label{subsubsec:integration_challenges}

\textbf{یکپارچگی با سیستم‌های موجود}:
\begin{itemize}
\item \textbf{استانداردهای بهداشتی}\footnote{Healthcare Standards Compliance}: سازگاری با استانداردهای اچ‌ال‌هفت فایر، دایکام و اسنومد سی‌تی
\item \textbf{امنیت داده‌ها}\footnote{Data Security Requirements}: رعایت قوانین حفاظت از اطلاعات بیماران (هیپا، جی‌دی‌پی‌آر) و رمزنگاری داده‌های حساس
\item \textbf{قابلیت تعامل}\footnote{Interoperability Issues}: اتصال به سیستم‌های مدیریت اطلاعات بیمارستان (اچ‌آی‌اس) و سیستم‌های رکورد الکترونیک (ای‌اچ‌آر)
\item \textbf{مدیریت نسخه‌ها}\footnote{Version Management}: هماهنگی بین \lr{23} وابستگی خارجی و اطمینان از سازگاری نسخه‌ها
\end{itemize}

\textbf{چالش‌های زیرساختی}:
\begin{itemize}
\item \textbf{منابع محاسباتی}\footnote{Computational Resources}: نیاز به منابع قابل‌توجه برای آموزش \lr{24} مدل مختلف و پردازش بلادرنگ
\item \textbf{ذخیره‌سازی داده‌ها}\footnote{Data Storage Challenges}: مدیریت \lr{4} پایگاه‌داده مختلف (مدل‌ها، داده‌ها، دانش، سیستم) با حجم بالای داده‌ها
\item \textbf{پشتیبان‌گیری و بازیابی}\footnote{Backup and Recovery}: اطمینان از در دسترس بودن مداوم سیستم و حفظ یکپارچگی داده‌ها
\item \textbf{مانیتورینگ سیستم}\footnote{System Monitoring}: نظارت بر عملکرد \lr{5} داشبورد مختلف و تشخیص به‌موقع مشکلات
\end{itemize}

\subsubsection{چالش‌های کاربری و پذیرش}\label{subsubsec:user_adoption_challenges}

\textbf{طراحی رابط کاربری}:
\begin{itemize}
\item \textbf{تنوع کاربران}\footnote{User Diversity}: طراحی \lr{5} داشبورد متفاوت برای نقش‌های مختلف (کادر بالینی، مدیریت، مالی) با نیازهای متفاوت
\item \textbf{قابلیت استفاده}\footnote{Usability Challenges}: اطمینان از سادگی استفاده در محیط‌های پرتنش بیمارستانی
\item \textbf{آموزش کاربران}\footnote{User Training Requirements}: نیاز به آموزش جامع کادر برای استفاده مؤثر از سیستم
\item \textbf{مقاومت در برابر تغییر}\footnote{Change Resistance}: غلبه بر مقاومت کادر پزشکی در برابر استفاده از سیستم‌های خودکار
\end{itemize}

\textbf{اعتماد و پذیرش}:
\begin{itemize}
\item \textbf{اعتبار بالینی}\footnote{Clinical Validation}: اثبات کارایی سیستم در محیط‌های بالینی واقعی
\item \textbf{مسئولیت قانونی}\footnote{Legal Liability}: تعیین مسئولیت در صورت خطای سیستم و تأثیر بر تصمیمات پزشکی
\item \textbf{شفافیت تصمیمات}\footnote{Decision Transparency}: ارائه توضیحات واضح برای توصیه‌های سیستم به کادر پزشکی
\item \textbf{کنترل کیفیت}\footnote{Quality Control}: اطمینان از دقت و قابلیت اعتماد مداوم سیستم
\end{itemize}

\subsubsection{چالش‌های عملیاتی و نگهداری}\label{subsubsec:operational_challenges}

\textbf{نگهداری و به‌روزرسانی}:

\item \textbf{به‌روزرسانی مدل‌ها}\footnote{Model Updates}: نیاز به بازآموزی مداوم مدل‌ها با داده‌های جدید و تغییرات در الگوهای بیماری
\item \textbf{مدیریت تغییرات}\footnote{Change Management}: کنترل تأثیر تغییرات بر عملکرد سیستم و اطمینان از عدم اختلال در خدمات
\item \textbf{پشتیبانی فنی}\footnote{Technical Support}: ارائه پشتیبانی \lr{24/7} برای سیستم‌های بحرانی بیمارستانی
\item \textbf{مستندسازی}\footnote{Documentation Maintenance}: نگهداری مستندات فنی و کاربری به‌روز برای تیم‌های مختلف
\end{itemize}

\textbf{هزینه‌ها و منابع}:
\begin{itemize}
\item \textbf{هزینه پیاده‌سازی}\footnote{Implementation Costs}: سرمایه‌گذاری اولیه قابل‌توجه برای سخت‌افزار، نرم‌افزار و آموزش
\item \textbf{هزینه‌های عملیاتی}\footnote{Operational Costs}: هزینه‌های مداوم نگهداری، به‌روزرسانی و پشتیبانی سیستم
\item \textbf{بازگشت سرمایه}\footnote{Return on Investment}: اثبات مزایای اقتصادی سیستم و توجیه هزینه‌های آن
\item \textbf{تخصیص منابع انسانی}\footnote{Human Resource Allocation}: نیاز به متخصصان فنی برای نگهداری و توسعه سیستم
\end{itemize}

\subsubsection{چالش‌های قانونی و اخلاقی}\label{subsubsec:legal_ethical_challenges}

\textbf{مسائل قانونی}:
\begin{itemize}
\item \textbf{مقررات پزشکی}\footnote{Medical Regulations}: رعایت مقررات سازمان غذا و دارو و سایر نهادهای نظارتی
\item \textbf{حفاظت از داده‌ها}\footnote{Data Protection Laws}: پیروی از قوانین حفاظت از اطلاعات شخصی و پزشکی
\item \textbf{مسئولیت مدنی}\footnote{Civil Liability}: تعیین مسئولیت در صورت بروز خطا یا آسیب ناشی از سیستم
\item \textbf{حق مالکیت فکری}\footnote{Intellectual Property Rights}: حفاظت از الگوریتم‌ها و روش‌های توسعه‌یافته
\end{itemize}

\textbf{مسائل اخلاقی}:
\begin{itemize}
\item \textbf{تبعیض الگوریتمی}\footnote{Algorithmic Bias}: اطمینان از عدالت در تصمیمات سیستم برای گروه‌های مختلف جمعیتی
\item \textbf{حریم خصوصی}\footnote{Privacy Concerns}: حفاظت از اطلاعات حساس بیماران و کنترل دسترسی
\item \textbf{رضایت آگاهانه}\footnote{Informed Consent}: اطلاع‌رسانی به بیماران درباره استفاده از سیستم‌های هوش مصنوعی
\item \textbf{شفافیت و پاسخگویی}\footnote{Transparency and Accountability}: ارائه توضیحات واضح درباره نحوه عملکرد سیستم
\end{itemize}

این چالش‌ها نشان می‌دهند که پیاده‌سازی موفق سیستم‌های پشتیبانی تصمیم‌گیری در مراقبت‌های بهداشتی نیازمند رویکردی جامع و چندبعدی است که جنبه‌های فنی، انسانی، قانونی و اخلاقی را در نظر بگیرد.

\subsection{پیشنهادها برای بهبود پروژه و مسیرهای آتی}\label{subsec:recommendations}

\item \textbf{بهینه‌سازی رابط کاربری}: بهبود زمان پاسخ داشبوردها و اضافه کردن قابلیت‌های تعاملی بیشتر برای کاربران
